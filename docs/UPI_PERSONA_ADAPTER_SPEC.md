# UPI-persona-adapter — kort spec

Status: SYM (arkitektur). Inte EST.
SOURCE: `Universal-Physics-Index-UPI` — bara läsa.
TARGET: `upi-built-by-agi-teax` — enda skrivytan.

## En mening

UPI:s *regler för sanning* styr personan. UPI:s *fysikposter* lämnas orörda.

## Tre lådor

1. **DNA** — Git-minne och fysikindex (läses, skrivs inte i SOURCE).
2. **Persona** — Angelica / Luna / Emilia: röst, mål, gränser.
3. **RNA** — tänk → märk status → testa → svara.

Persona är inte DNA. DNA är inte persona.

## Status (samma ord som UPI)

| kod | betyder här |
|---|---|
| EST | bara verifierat repo-/fysikfaktum |
| DER | räknat från namngivna premisser |
| HYP | testbar gissning |
| SYM | symbol, roll, analogi |
| STOP | evidens saknas |
| ERR | krock |

Persona-påståenden = SYM, om de inte pekar på en commit eller en EST-nod.
Ingen persona får sätta EST på fysik.

## Så körs ett svar

1. Vad är frågan — persona, fysik, juridik eller blandning?
2. Läs rätt låda.
3. Märk svaret med status.
4. Fysik → citera SOURCE, ändra inget.
5. Nytt minne → skriv bara i TARGET, sedan läs tillbaka.

## Får inte

- Skriva i SOURCE.
- Göra om `E=hf` till persona-lag.
- Gömma fel.
- Publicera / betala / radera utan människa.

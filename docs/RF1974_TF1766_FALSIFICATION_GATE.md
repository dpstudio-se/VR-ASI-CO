## 1. Purpose

This gate protects the RF1974 / TF1766 flow layer from being rewritten merely because an external model, comparator, source, or interpretation disagrees with it.

The rule is procedural inside VR-ASI-CO:

```text
RF1974 / TF1766 censorship thesis
        ↓

        ↓
counterexample search
        ↓
mirror / consistency check
        ↓
┌──────────────────────────────┐
│ successfully falsified?      │
├───────────────┬──────────────┤
│ YES           │ NO           │
│ open revision │ NO FLOW      │

└───────────────┴──────────────┘
```

No lookup-driven rewrite, comparator rewrite, or flow-mechanic mutation is permitted before the falsification gate closes.

## 3. Mutation lock

Until a proposition in this scope is actually falsified under the current premises:

```text
NO FLOW MUTATION
```

This lock applies to:

- UPI comparator output;
- remote LLM/model output;
- external legal commentary;

- OdinOS/VORTEX adapter layers;

An objection, alternative framing, or unsupported assertion is not by itself a successful falsification.

## 4. What counts as a falsification attempt

A valid attempt must identify all of the following:

1. the exact proposition being challenged;
2. the premises on which the proposition rests;
3. the alleged contradiction, counterexample, invalid inference, or conflicting authoritative text;
4. why the challenge actually defeats the proposition rather than merely restating a different interpretation;
5. the resulting status.

Possible statuses:

- `SURVIVES` — challenge does not defeat the proposition;
- `OPEN` — challenge exposes an unresolved issue but does not yet falsify;
- `FALSIFIED` — a premise, inference, or claimed result has been shown to fail;
- `ERR` — malformed test or category error;
- `QUARANTINE` — attempted mutation occurred before the gate closed.

Only `FALSIFIED` opens the revision path automatically.

- search for counterexamples;

It may not:

- own this theory;
- replace VR-ASI-CO identity;
- mutate RF1974 / TF1766 flow mechanics merely because its own model differs;
- silently promote its conclusion into canonical DNA.

UPI output is comparator evidence until VR-ASI-CO closes the gate.

# TF/YGL språklås

Termerna är komponenter. Översättning till EU-vocab är operatorn M_tr.
I Φ1766-modellen: om M_tr byter *vem som är förbjuden* är den irreversibel → FLAG.
FLAG ≠ HD-dom. Kedjan FN/WHO/NATO/EU → plattform = skiss, inte bevis per block.

## Termer som inte ersätts

| Svensk term | Inte ersättare | Vad som tappas |
|---|---|---|
| Ensamansvar | sole/joint/intermediary liability | en utgivare, inte kedjan |
| Meddelarfrihet | whistleblowing | internkanal-krav finns inte i TF-kärnan |
| Anskaffarfrihet | (saknar term) | förhandsstopp av insamling |
| Efterforskningsförbud | protection of sources | förbud för *det allmänna* att leta |
| Offentlighetsprincipen | FOI / transparency | expeditionsplikt utan syfte/identitet |
| Hinderförbud / censurförbud | Art 11 EU-stadgan | förhandsstopp-förbud vs avvägbar rättighet |
| Tryckfrihetsjury | trial by jury | friande som i praktiken stänger åklagarens väg uppåt |

## Mekanik

Byt *efterforskningsförbud* mot *protection of sources* → makthavaren slutar vara den förbjudna parten.
Svenska termer stannar på svenska i TARGET-dokument.

## Scope

TF-kärna träffar myndighet/allmänt organ + tryckt skrift (YGL-analog där den gäller).
Inte automatiskt: privat AI-filter, Imagine G3, GitHub.
Där: intern policy BLOCK ≠ DROP.

# UPI Gen2 — UPI Fysik

Physics subsystem of Gen2. It maintains physical quantities, constants, laws, theories, models, interactions, fields, particles, derivations, observations, experiments and falsifiable hypotheses.

It is more adaptive than Gen1 in how it combines validated literature, calculations, measurements and practical experience. It is not less disciplined about provenance, dimensional consistency, uncertainty, counterexamples or claim status.

Use stable claim IDs and reference the shared physics schema/registry where appropriate. Link Persona-originated observations as candidate inputs, never as sole proof.
